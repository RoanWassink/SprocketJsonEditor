# Sprocket JSON Editor 0.1.0 — Beta

First public release of the reusable editor used by Shell Selector and Material Selector: expandable shared entries, add/duplicate controls, dropdowns, field validation, scrolling, input blocking and provider-owned Save and refresh. Install once; included in the full pack.
